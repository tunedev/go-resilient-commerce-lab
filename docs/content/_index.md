---
title: "go-resilient-commerce-lab"
---

A local, runnable Go microservices lab that reproduces the failure modes real
distributed backends face. Each slice ships working code, a one-command
reproducible demo, and a post written from what actually happened. The
repository is on GitHub at
[tunedev/go-resilient-commerce-lab](https://github.com/tunedev/go-resilient-commerce-lab).
